## How to contribute

The quickest path: **edit `website/projects.json`**, run `npm run build`, and open a Pull Request.

```jsonc
// website/projects.json — add your entry:
{
  "name": "Your Project",
  "description": "What it does in one clear sentence.",
  "emoji": "🚀",
  "tech": ["Python", "API"],
  "author": "yourusername",
  "authorUrl": "https://github.com/yourusername",
  "repo": "https://github.com/yourusername/your-project",
  "stars": 0,
  "letter": "Y",
}
```

Then run:

```bash
npm run validate   # checks your entry is valid
npm run build      # regenerates this README
```

See [CONTRIBUTING.md](CONTRIBUTING.md) for full guidelines.
